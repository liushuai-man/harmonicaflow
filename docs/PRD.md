> v0.2.0 变更摘要：跟吹视图**只保留纵向落块**（取消横向卷轴）；新增**深色/浅色主题**（主色可调）；纵向加入**近大远小透视**；音块触碰判定线时播放**触碰特效**；底部标注 **1234567 简谱音阶**；所有可配置项**集中到统一设置页**；出包方式改为 **EAS 云端构建**（本地不依赖 Java）。

## 1. 产品定位

> **把一份乐谱，变成能跟着吹的动态音块。**

用户导入乐谱 → 系统自动解析并编配到具体口琴的孔位 → 屏幕上的音块随时间移动，用户跟着吹。

产品的复杂度（格式解析、孔位映射、编配选优）全部留在后台；前台只做一件事：**看着音块吹**。

近期以 Android 个人离线练习为交付主线，同时积累可复用的跨端能力。电脑练习与技术博客展示是扩展方向，尚未开发为完整 Web 产品；博客中的独立展示模块负责项目介绍、演示和体验入口，不复制一套解析/编配算法，也不意味着必须引入后端。

“零配置”指支持范围内无需逐曲编配、调视觉或配网络服务即可练习。系统无法从乐谱推断实体琴型号：默认针对明确标注的琴型/音阶表，其他琴型需要选用相符预设，品牌差异仍需校对。不得为保持零配置口号而隐藏不匹配或不可吹音。

## 2. 目标用户与场景

| 用户 | 场景 |
|---|---|
| 口琴初学者 | 拿到一首曲子，不知道该吹哪个孔，需要直观的"看谱跟吹" |
| 进阶练习者 | 需要放慢速度（0.5x）反复跟吹难点片段 |
| 有乐谱资源的人 | 手上有 MuseScore / 打谱软件导出的 MusicXML，希望直接变成口琴练习谱 |

---

## 3. 核心价值

1. **自动**：导入即完成解析 + 孔位编配，无需手工转谱。
2. **直观**：方块长度 = 吹奏时值；颜色区分吹/吸；轨道 = 孔位（随落块方向为列或行），直接告诉你"吹哪个孔、吹还是吸"。
3. **可用**：吹不出的音会被明确标出并给出建议，而不是默默出错。
4. **好看**：白线 + 黑白灰渐变的极简视觉（默认皮肤），像「钢琴瀑布」一样流畅；音块压线时音块/判定线/音阶同步高亮，节奏感强、长时间看不累。
5. **轻**：无账号、**默认离线**（仅可选开启的「在线随机封面」会联网）、无音频依赖，装上就能用。

## 4. 用户主流程

```
打开 App
   │
   ├─（首次）曲库已有内置示例曲 ──→ 点一下 ──→ 直接进入跟吹页    ← 1 次点击
   │
   └─ 点「导入乐谱」→ 选文件 → 自动解析/编配 → 直接进入跟吹页    ← 2 次点击
```

跟吹页：`播放/暂停` · `重播` · `倍速 0.5/0.75/1.0` · `进度拖动`（落块方向由设置决定，默认自动；跟吹页自身只保留播放相关操作）

## 5. 功能范围

### 5.1 MVP 包含

| 模块 | 内容 |
|---|---|
| 乐谱导入 | JSON / ABC 记谱 / MusicXML（.musicxml/.xml/.mxl） |
| 自动分析 | 解析音高与时值 → 编配到口琴孔位与吹吸 → 标记不可吹音 |
| 口琴预设 | 24 孔复音 / 单音 24 孔 / 10 孔布鲁斯 / 半音阶，可切换；调号、孔数与逐孔音阶表均可修改 |
| 跟吹视图 | **落块方向可自由选择**：**从上到下** / **从左到右** / **自动**（默认，按屏幕宽高比自动选向）；判定线随方向落在底部横线 / 右侧竖线；方向是对用户开放的偏好，不是硬约束 |
| 视角 | **预设三档**（垂直 / 弱 / 强）+ **高级角度滑块**（`0°`–上限，`0°` = 完全垂直）；透视距离由几何算法反推，各机型自适应 |
| 视觉风格 | **白线皮肤（默认）**：黑白灰渐变背景 + 白色线条，参考抖音「可视化钢琴」；可**一键切回彩色皮肤**；**透明度**与**主题色**可调 |
| 横向琴谱 | 跟吹页的可选水平琴谱条：**完整谱面** / **判定线附近精简提示条** / **关闭**，三态可切换 |
| 音乐封面 | 跟吹页展示曲目封面；**本地优先**（内置或用户导入），**在线随机封面**为可选开关（默认关；拉取后缓存到本地，离线自动回退） |
| 命中高亮 | 音块压线瞬间，**音块、判定线该列、底部音阶标注**三者**同步高亮（hover 联动）**，交互过渡自然不卡顿 |
| 触碰特效 | 音块抵达判定线时按该音色播放一次脉冲环特效（特效可插拔，后续可扩展更多样式） |
| 主题外观 | 深色 / 浅色 / 跟随系统；皮肤（白线 / 彩色）；主色、透明度可调 |
| 播放控制 | 播放 / 暂停 / 重播 / 倍速 / 进度拖动 |
| 曲库 | 内置示例曲 + 导入曲持久化保存 |
| 入门练习 | 音阶上下行、三音级进、长短音与休止；按当前音阶表生成，复用瀑布跟吹 |
| 基础乐理 | 内置六节读谱小课堂：简谱与孔号、八度与升降号、时值与休止、拍号与速度、大调、吹吸动作 |
| 统一设置页 | 集中外观（深浅 / 皮肤 / 主色 / 透明度）/ 跟吹视图（方向 / 视角 / 横向琴谱）/ 封面 / 口琴预设 / 音阶表校对 |

### 5.2 明确不做（本版）

- **伴奏持久化绑定与自动音频对齐**（临时选择伴奏已实现，真机同步待验；绑定属 T4）
- 节拍器、录音对比
- MIDI 文件解析
- 账号、云同步、分享（本版无后端，仅预留接口位置）
- 五线谱 / 简谱的排版渲染（横向琴谱只做提示条，不做专业排版）
- 压音（bending）与超吹的教学指导

## 6. 界面说明

### 6.1 曲库首页 `src/app/index.tsx`
- 顶部标题 + 右侧「设置」入口
- 曲目列表（曲名 / 来源格式 / 音块数 / 不可吹音数）
- 底部主按钮：**导入乐谱**（唯一的强调色按钮）
- 空列表时有内置示例曲兜底，保证永远有可点内容

### 6.2 跟吹页 `src/app/practice/[id].tsx`
- 顶部：曲目**封面** + 曲名 + 当前口琴预设 + 不可吹音提示条（有才显示）
- 中部：音块时间轴（占屏主要区域）
  - **落块方向**（三选一，设置项决定；默认**自动**）：
    - **自动**（默认）：按可视区宽高比自动选向——竖屏走"从上到下"，横屏走"从左到右"
    - **从上到下**：X=孔位列、Y=时间；方块自上而下流入，**底部横线**为判定线
    - **从左到右**：Y=孔位列、X=时间；方块自左向右流入，**右侧竖线**为判定线
  - **近大远小**：以判定线为基准做透视，远端收窄、近端正常（垂直视角时无透视）
  - **白线皮肤**：黑白灰渐变背景 + 白色线条；判定线/孔列分隔/音块边框均为细白线
  - 吹 = 亮块（白→浅灰渐变），吸 = 空心描边块（白色描边）；块内标注为辅助。不可吹音使用可辨识的特殊描边/弱化样式，不牺牲对比与提示
  - 底部演奏面板（横向落块时在判定线一侧）：集中表达孔号与吹/吸，半音阶还需明确推键；简谱是辅助信息。瀑布主要表达时机与持续时间，不要求用户追读移动音块。此为信息设计要求，动作级高亮与小屏可读性仍需按 T1 验证。
  - **横向琴谱**（可选）：跟吹页一条水平琴谱，三态——**完整谱面** / **判定线附近精简提示条**（只显示即将到来的 1–2 小节）/ **关闭**
- **命中高亮（hover 联动）**：方块压线瞬间，**该音块 + 判定线对应那一段 + 底部该孔音阶**三者同时高亮一下（约 150–250ms，随后回落），给"该吹了"一个即时、连贯的视觉提示
- 触碰特效：方块抵达判定线的瞬间，在该列播放一次脉冲环特效（与命中高亮叠加，可插拔）
- 底部：播放条（播放/暂停、重播、倍速、进度拖动）
- **伴奏**（顶部入口）：临时选本地音频，倍速同步作用于伴奏，不选也能跟吹。当前前提是音频起点、速度与谱面匹配；周期校时不等于自动识别前奏、反复和演奏变速，不能承诺任意录音自动对齐。

### 6.3 统一设置页 `src/app/settings.tsx`
- **外观**：主题模式（跟随系统 / 浅色 / 深色）、**皮肤**（白线 / 彩色）、主色选择、**透明度**
- **跟吹视图**：**落块方向**（从上到下 / 从左到右 / 自动）、**视角**（预设：垂直 / 弱 / 强，另有高级角度滑块 `0°`–上限）、**横向琴谱**（完整 / 精简提示条 / 关闭）
- **封面**：封面来源（本地优先 / 开启在线随机图）、清除封面缓存
- **口琴**：预设切换（四个预设单选）
- **音阶表校对**：可**选择调号**（换调按就近半音整表移调）、**增删孔数**，并逐孔修改吹/吸（半音阶含推键列）后保存
- 说明文案：提示用户用自己的琴核对；提示"开启在线随机封面需要联网"
- 原则：持久偏好集中在设置页并区分常用/高级；播放、伴奏与曲目封面等上下文操作可留在相关页面，避免为了集中设置打断练习。

### 6.4 视觉风格（皮肤）
- **白线皮肤（默认）**：整屏**黑白灰渐变背景**（自上而下由黑到灰的柔和渐变），所有结构线条为**细白线**——判定线、孔列分隔线、音块描边、时间刻度线；音块为白/灰渐变实体。整体接近抖音「可视化钢琴」的极简观感，长时间看不累。
- **彩色皮肤**：保留现有「吹暖 / 吸冷」的彩色音块与彩色判定线，供偏好高对比度的用户切换。
- 两套皮肤**共用同一套几何与布局**，只替换配色与线条策略；深浅色模式在两套皮肤下都生效（白线皮肤在浅色模式下为"白底黑灰线"，深色模式下为"黑底白线"）。
- **透明度**：可调音块与背景的透明程度（如"实体 / 半透明 / 通透"），通透档能透过音块看到背景线条，视觉更轻盈。
- **个性化原则（v0.6.0）**：默认外观必须完整统一；已有皮肤、主色、方向等偏好保留，常用与高级分层。新增视觉维度不自动成为设置项，须说明用户需要、合法组合与验收成本。品牌主色不能覆盖吹吸语义，任何风格不得关闭关键孔位/动作提示或牺牲可读性。几何参数归 `core/visual/`，配色与通用样式归 `theme/`，不把所有视觉数据混入一个模块。
- **品牌定档**：白线/彩色是当前实现基线，不是永久风格上限。新的视觉方向需结合真机截图与方案比较由用户选择；本次只确立 [UI_DESIGN.md](./UI_DESIGN.md) 的设计规则，不指定新材质、色值或默认角度。

### 6.5 入门练习 `src/app/learn/`

- 首页「从第一声开始」进入学习页：上半区为三项练习，下半区为可展开的六节读谱知识，默认展开第一节。
- 练习以当前琴型、调号及校对后的音阶表为准，从最低的完整大调八度生成；不要求导入谱面，不写入曲库。
- 统一 4/4、四分音符=60 BPM，提供播放、暂停、重播、倍速和定位。保留原有瀑布、底部孔位/吹吸、方向和主题偏好；离开练习页暂停，重新选择练习或更换琴型后归零。
- 缺少完整八度时禁用练习并提示核对设置；未知练习地址明确提示返回。软件调号必须匹配实体琴，不自动识别实体乐器。
- 内容与练习完全离线；不含示范音、节拍器、录音评分、学习进度同步或专业五线谱排版。到点高亮仅表示演奏时机。

## 7. 交互细节

- **起吹留白**：播放时预留约 2 秒 lead-in，让第一个音块从容走到判定线，避免"一按就开始吹"。
- **不可吹音**：以可辨识的特殊样式显示并说明原因；建议只能引用已支持且经过验证的能力，不暗示已有自动移调或强行替代音高。
- **到点高亮**（代码沿用“命中”命名）：表示“现在该吹”，不表示用户吹对了；应关联音块、判定线与底部对应动作。高亮走 UI 线程动画，流畅性以目标设备实测为准，不能承诺任何情况下都不掉帧。
- **触碰反馈**：音块抵达判定线即触发一次特效，给"该吹了"一个即时视觉提示（默认脉冲环，后续可扩展）。
- **控件交互反馈**：所有可点元素（按钮 / 分段控件 / 列表行 / 滑块）具备按压与悬停（PC/Web 指针悬停）的过渡反馈，过渡时长统一，观感连贯自然。
- **动画连贯性**：正常播放时间轴保持连续位移（seek/restart 的位置改变是明确的用户操作）（不依赖窗口重算改坐标），切方向 / 切皮肤 / 调视角时也不打断当前滚动位置。
- **状态记忆**：上次选用的口琴预设、倍速、主题模式、**皮肤**、**透明度**、主色、**落块方向**、**视角**、**横向琴谱**在重启后保留。
- **主题跟随**：选择"跟随系统"时随系统深浅色即时切换，无需重启。
