# 口琴跟吹助手 HarmonicaFlow — 产品需求文档（PRD）

- 版本：v0.1.0
- 日期：2026-10-05
- 状态：已确认（MVP 范围）

---

## 1. 产品定位

> **把一份乐谱，变成能跟着吹的动态音块。**

用户导入乐谱 → 系统自动解析并编配到具体口琴的孔位 → 屏幕上的音块随时间移动，用户跟着吹。

产品的复杂度（格式解析、孔位映射、编配选优）全部留在后台；前台只做一件事：**看着音块吹**。

---

## 2. 目标用户与场景

| 用户 | 场景 |
|---|---|
| 口琴初学者 | 拿到一首曲子，不知道该吹哪个孔，需要直观的"看谱跟吹" |
| 进阶练习者 | 需要放慢速度（0.5x）反复跟吹难点片段 |
| 有乐谱资源的人 | 手上有 MuseScore / 打谱软件导出的 MusicXML，希望直接变成口琴练习谱 |

---

## 3. 核心价值

1. **自动**：导入即完成解析 + 孔位编配，无需手工转谱。
2. **直观**：方块长度 = 吹奏时值；颜色区分吹/吸；行 = 孔位，直接告诉你"吹哪个孔、吹还是吸"。
3. **可用**：吹不出的音会被明确标出并给出建议，而不是默默出错。
4. **轻**：无账号、无网络、无音频依赖，装上就能用。

---

## 4. 用户主流程

```
打开 App
   │
   ├─（首次）曲库已有内置示例曲 ──→ 点一下 ──→ 直接进入跟吹页    ← 1 次点击
   │
   └─ 点「导入乐谱」→ 选文件 → 自动解析/编配 → 直接进入跟吹页    ← 2 次点击
```

跟吹页：`播放/暂停` · `重播` · `倍速 0.5/0.75/1.0` · `横向/纵向 视图切换`

---

## 5. 功能范围

### 5.1 MVP 包含

| 模块 | 内容 |
|---|---|
| 乐谱导入 | JSON / ABC 记谱 / MusicXML（.musicxml/.xml/.mxl） |
| 自动分析 | 解析音高与时值 → 编配到口琴孔位与吹吸 → 标记不可吹音 |
| 口琴预设 | 24 孔复音 / 10 孔布鲁斯 / 半音阶，可切换；音阶表可校对修改 |
| 跟吹视图 | 横向卷轴（方块自右向左）+ 纵向落块（方块自上而下），可切换 |
| 播放控制 | 播放 / 暂停 / 重播 / 倍速 / 进度拖动 |
| 曲库 | 内置示例曲 + 导入曲持久化保存 |

### 5.2 明确不做（本版）

- 音频播放、节拍器、录音对比
- MIDI 文件解析
- 账号、云同步、分享
- 五线谱 / 简谱的排版渲染
- 压音（bending）与超吹的教学指导

## 6. 界面说明

### 6.1 曲库首页 `src/app/index.tsx`
- 顶部标题 + 右侧「设置」入口
- 曲目列表（曲名 / 来源格式 / 音块数 / 不可吹音数）
- 底部主按钮：**导入乐谱**（唯一的强调色按钮）
- 空列表时有内置示例曲兜底，保证永远有可点内容

### 6.2 跟吹页 `src/app/practice/[id].tsx`
- 顶部：曲名 + 当前口琴预设 + 不可吹音提示条（有才显示）
- 中部：音块时间轴（占屏主要区域）
  - 横向：X=时间、Y=孔位行；固定竖线为当前演奏位置
  - 纵向：X=孔位列、Y=时间；底部横线为判定线
  - 吹 = 暖色，吸 = 冷色；块内标注孔号与音名；不可吹音用醒目描边
- 底部：播放条（播放/暂停、重播、倍速、视图切换）

### 6.3 设置页 `src/app/settings.tsx`
- 口琴预设切换（三个预设单选）
- 当前预设的音阶表（孔号 ↔ 音名 ↔ 吹/吸），支持逐孔修改并保存
- 说明文案：提示用户用自己的琴核对

---

## 7. 交互细节

- **起吹留白**：播放时预留约 2 秒 lead-in，让第一个音块从容走到演奏线，避免"一按就开始吹"。
- **不可吹音**：时间轴照常显示该音块（虚线/描边），提示条给出"移调 ±8 度"或"更换口琴预设"的建议。
- **状态记忆**：上次选用的口琴预设、视图方向、倍速在重启后保留。

---

## 8. 成功标准（可量化）

| 指标 | 目标 |
|---|---|
| 从打开 App 到进入跟吹页 | ≤ 2 次点击 |
| 导入到可跟吹 | 无中间确认页，解析在 1 秒内完成（常见流行曲长度） |
| 滚动帧率 | 3 分钟以上曲目稳定无卡顿 |
| 编配正确性 | 可吹音 100% 落在正确的孔位/吹吸上（以用户校对后的音阶表为准） |
| 依赖数量 | 运行时依赖 ≤ 6 个 |
